14.4. A Concrete Dissipative Map on the Interval🔗

The manuscript needs more than mere non-surjectivity: it needs a non-singular, dissipative map. The model example is the halving map

f : [0,1] \to [0,1], \qquad f(x) = x/2.

It has all the required properties at once:

  • Injective — distinct inputs give distinct outputs.

  • Not surjective — the value 1 (indeed anything in (1/2, 1]) is never reached; the past of those states is missing.

  • Dissipative — it sends an interval [a,b] to [a/2, b/2], halving its Lebesgue length.

  • Non-singular — a set of positive length is sent to a set of positive (halved) length; null sets stay null and positive-measure sets stay positive-measure.
