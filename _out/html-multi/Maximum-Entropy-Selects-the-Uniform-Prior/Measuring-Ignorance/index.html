5.1. Measuring Ignorance🔗

The previous chapter singled out the uniform prior as the unique relabeling-invariant one. There is a second, independent route to the same destination, due to Jaynes: the uniform prior is the distribution that maximizes the Shannon entropy, and so it is the prior that assumes the least.

For a probability distribution p on a finite non-empty space \alpha with n = |\alpha| outcomes, the entropy is

H(p) = \sum_{i} -p_i \log p_i,

with the convention 0 \log 0 = 0. Entropy measures spread: it is small when the distribution is concentrated on a few outcomes and large when the mass is spread out. The claim we prove is:

Among all distributions on n outcomes, the uniform distribution u_i = 1/n uniquely maximizes the entropy, and the maximum value is \log n.

This is the maximum-entropy principle: if the only thing you know about a system is the set of possibilities, the honest prior is the one with the largest entropy, namely the uniform one. Any other prior is secretly assuming extra information that you do not have.
